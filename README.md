# portfolio-site — витрина фрилансера

Одностраничный сайт, куда ведёт ссылка из профиля на FL.ru, Kwork, Авито и в Telegram.
Сделан на чистых HTML, CSS и JavaScript: без сборки, без npm, без зависимостей и без интернета.
Открывается двойным щелчком по `index.html`.

## Что внутри

- **Герой** — чем вы занимаетесь и какую боль снимаете, с тремя цифрами результата
- **Услуги** — четыре оффера, ровно как в лестнице из `01-nisha-i-pozicionirovanie.md`
- **Кейсы** — три карточки под ваши реальные репозитории со скриншотами
- **Калькулятор стоимости** — интерактивный расчёт на JS: клиент отмечает задачи и видит цену и срок
- **Как работаем** — процесс из пяти шагов, снимает страх предоплаты
- **FAQ** — закрывает главное возражение «у вас нет коммерческого опыта»
- **Контакт** — кнопка в Telegram

## Что заменить перед публикацией

Откройте `index.html` и найдите комментарии со словом `ЗАМЕНИТЕ` (или поищите по тексту):

| Что | Где встречается | На что заменить |
|---|---|---|
| `https://t.me/ВАШ_НИК` | 4 раза (шапка, герой, калькулятор, контакт) | ваша ссылка в Telegram |
| `https://github.com/ВАШ_ЛОГИН` | 2 раза (контакт) + 2 ссылки на репозитории в кейсах | ваш профиль и ваши репозитории |
| `Ваше Имя` | подвал | ваше имя или ник |
| `assets/mp-monitor.png` | кейс 1 | скриншот дашборда `mp-monitor` |
| `assets/ai-support-bot.png` | кейс 2 | скриншот диалога с ботом |
| `assets/landing.png` | кейс 3 | скриншот этой страницы |

Также поправьте цены в калькуляторе (`data-price` и `data-days` у каждого пункта) под свой прайс.
Дата в подвале подставляется автоматически.

## Проверка перед публикацией

**Запусти это до того, как давать ссылку кому-либо:**

```bash
node tools/prepublish-check.js
```

Скрипт проверяет пять вещей и возвращает код 1, если публиковать рано:

1. **Остались ли заглушки** — `ВАШ_НИК`, `ВАШ_ЛОГИН`, `Ваше Имя`. Показывает номер строки каждого.
2. **Куда ведут ссылки Telegram** — если на заглушку, это ошибка.
3. **Все ли картинки кейсов на месте** — отсутствующий файл даст пустое место на сайте.
4. **Не пропали ли блоки** `#services`, `#cases`, `#calc`, `#process`, `#faq`, `#contact`.
5. **Технические требования** — адаптив под телефон, meta viewport, осмысленный `title`, отсутствие внешних зависимостей.

Сейчас он ожидаемо ругается на 8 заглушек: 4 ссылки Telegram, 3 ссылки GitHub и имя в подвале.
После замены должен писать «ВСЁ ГОТОВО К ПУБЛИКАЦИИ».

## Проверка калькулятора

Логика расчёта покрыта тестом, который выполняется без браузера:

```bash
node tools/check-calculator.js
```

Скрипт вытаскивает встроенный `<script>` прямо из `index.html`, подставляет минимальную заглушку DOM
и проверяет пять сценариев: состояние по умолчанию, снятие всех галочек, выбор всех пунктов,
один пункт и форматирование разрядов. Если поменяешь цены или добавишь пункт — прогони тест снова.

## Как сделать скриншоты для кейсов

1. Запустите проект, откройте его в браузере.
2. Сделайте снимок окна (Win + Shift + S).
3. Обрежьте до соотношения примерно 16:10 — карточка кейса сама впишет картинку.
4. Положите файлы в папку `assets/` с теми именами, что указаны выше.

## Как опубликовать (бесплатно, 5 минут)

**Вариант 1 — GitHub Pages (рекомендую):**
1. Создайте репозиторий `portfolio-site`, загрузите туда `index.html`, папку `assets` и этот README.
2. Settings → Pages → Source: `Deploy from a branch` → Branch: `main`, папка `/ (root)` → Save.
3. Через минуту сайт будет доступен по адресу `https://ваш_логин.github.io/portfolio-site/`.

**Вариант 2 — Netlify Drop:**
Заходите на `app.netlify.com/drop` и перетаскиваете папку целиком. Ссылка появится сразу.

**Вариант 3 — свой домен:**
Купить домен вида `вашеимя.ru` (200–400 ₽/год) и направить на GitHub Pages. Для фрилансера это заметно повышает доверие.

## Важно

Ссылку на этот сайт ставьте **первой строкой** в профиле на каждой площадке и в закреплённом сообщении Telegram.
Заказчик не должен искать ваши кейсы — он должен попадать на них одним щелчком.
